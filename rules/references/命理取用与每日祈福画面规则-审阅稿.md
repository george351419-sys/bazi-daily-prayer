## 1. 依据与边界

- 格局主依据：《子平真诠》论用神、论用神成败救应、各格专章。采用东里书斋的古籍正文，校注与原文分开处理。
- 月令取用：https://www.donglishuzhai.net/chapter/3721.html
- 成败救应原文转载：https://www.mingsage.com/zh/classics/zi-ping-zhen-quan/lun-yong-shen-cheng-bai-jiu-ying
- 印格条件：https://www.donglishuzhai.net/chapter/3748.html
- 气候权变：https://www.donglishuzhai.net/chapter/3727.html
- 刑冲会合：https://www.donglishuzhai.net/chapter/3720.html
- 调候依据：《穷通宝鉴》维基文库文本：https://zh.wikisource.org/zh-hant/穷通宝鉴 。本次读取其 API 所返回的全文，按日干与月令归纳。它是特定传本，不能等同于所有版本或徐乐吾评注本。

传统取用是文化解释体系，没有证明生肖图像、颜色会改变运势。产品可以采用象征设计，但不得将图像视为新增的真实干支，或宣称已实际完成合化、解冲。

下文“候选”指特定条件下传统体系认可的取用方向，不是直接的现实吉凶结论。古籍中的贫富、疾病、寿命、性别贬损断语不进入用户内容。

## 2. 三种方法必须采用不同字段

格局法的“用神”常指月令立格之神，不等于扶抑法中改善平衡的五行。融合时应使用“成格所需的相神、救应与辅助条件”，而不是直接把月令用神加入喜用集合。

建议输出：

- 扶抑：日主强弱结论、普通格或特殊格、可用五行、条件性可用五行、明确不宜五行、依据。
- 格局：月令立格、成败状态、所需十神、实际对应天干、成格条件、破格条件。
- 调候：日干、出生月令、节气阶段、候选天干、主辅关系、并用要求、替代关系、制约条件。
- 产品：主五行、次五行、配色、生肖候选、符号来源、排除理由。

“水日主身强”只能初步提出木泄、火耗、土制的可能方向。土也可能生金助水；木泄水、制土、生火的不同后果须看全局。普通身强与从旺、润下等特殊情况不能走同一规则。

## 3. 格局规则

### 3.1 立格与判定流程

1. 以出生月令为提纲，检查藏干、透干及会支；月令本气、透出之神、会局改变须分别记录。
2. 多个藏干透出时，保留候选格和取舍依据，不机械按出现次数定格。
3. 辰戌丑未杂气另建规则；建禄、月劫和阳刃另判。
4. 官杀混杂、印食冲突、财印相碍、合去关键字等，先检查成败救应。
5. 特殊从格、化格、专旺等单独处理，本稿不以八格表代替其成立条件。
6. 完成原局判定后，再检查大运及岁月日是否改变关键条件，原局与动态判断分开存储。

### 3.3 “偏印格喜财”的适用条件

必须区分：偏印立格、印重身强、印轻身弱、以及偏印确实妨碍食神。四者不是同一条件。

- 印重身强，财能抑印且不过度：财可进入格局辅助候选。
- 食神为关键用途而被偏印妨碍，财能制枭存食：财可进入救应候选。
- 印轻身弱，财再坏印：不能仅因“偏印格”就选财。
- 身强印旺但食伤泄秀路线成立：食伤也可成为候选，并非只能选财。
- 官印相生与杀印相生，须保留独立判断路径。

因此，水日主的财为火成立，但“偏印格 -> 火”只在对应条件满足时成立。壬的丙为偏财、丁为正财；癸的丙为正财、丁为偏财。程序必须保留阴阳干区别。

| 文本歧义 | 保存原文与待审核标记，不擅自统一 | 壬未月开头与结语的辛、癸、甲排序；甲丑月起句与结语侧重点不同 |

不能以“金、木同为调候候选”就得出“木可以独立解决调候”。例如某路线需要庚与甲配合，而扶抑排除金，则只剩木时应标记“原组合未满足”，不能直接视为完整调候共识。

本稿没有穷尽书中每一个特殊命例。表格是候选入口，条件表是自动化所需的最低结构；未录入的例外不应由大模型临时编补。

## 5. 按用户优先级融合

采用用户提出的“扶抑 > 格局 > 调候”作为产品排序策略。它不是三部古籍共同规定的统一优先级。《子平真诠》配气候篇有调候为急的权变，因此此策略与原典可能出现差异，须留下记录。

设 F 为扶抑可用集合，G 为经条件验证的成格/救应辅助集合，T 为经条件验证的调候集合。先完成具体天干、组合及禁忌检查，再映射五行。

排序：

1. F ∩ G ∩ T。
2. (F ∩ G) 去除上一档。
3. (F ∩ T) 去除前两档。
4. F 的其余有效候选。

同一档内，先按扶抑需要强度，再按格局关键性、调候紧迫性、原局是否已有足够支持排序。量化权重需由用户确认，不假装是传统定数。

以用户示例：F={木、火、土}，G={火}，T={金、木}，在三个集合均经条件确认的情况下，结果为火 > 木 > 土，金不因调候需要就越过扶抑门槛。

保护规则：

- 合并前仍保留丙丁等具体干区别，配色阶段才降维为五行。
- 若三法冲突且没有有效交集，不伪造“最佳共识”；说明采用扶抑优先的取舍。
- 如果只有一种五行可靠，不为了主辅配色强造第二喜用；辅色可用中性色，并标为审美配色。
- 特殊格、极端寒暖燥湿、组合无法满足，进入人工复核。
- 原局主次喜用稳定保存；动态推荐每日单独计算，不能悄悄覆盖原局结论。

## 6. 大运、岁月日的组合口径

每日分析状态应为“原命四柱 + 当前大运 + 流年 + 流月 + 流日”；有明确推送时点才另加入流时。

可以另排当时的年、月、日、时四柱，但不能把大运、流年、流月、流日拼成一份与出生四柱同义的命盘。大运是独立层，不是流年历法的年柱，也不用于替换月干推导的年干。

所有新增天干的十神继续相对于原命日干计算。若改用流日日干重新定十神，须说明是在分析当时的独立四柱，不能混成用户的财官印食。

排盘需固定出生时区、采用的时间口径、节气换月、立春换年、换日规则、起运顺逆和交运计算。每个字保存来源层级与有效时间；大运交接、节气当天尤其检查。

## 7. 生肖选择规则

### 7.1 基础对应

| 地支 | 生肖 | 本气五行 | 常用藏干 |
|---|---|---|---|
| 子 | 鼠 | 水 | 癸 |
| 丑 | 牛 | 土 | 己癸辛 |
| 寅 | 虎 | 木 | 甲丙戊 |
| 卯 | 兔 | 木 | 乙 |
| 辰 | 龙 | 土 | 戊乙癸 |
| 巳 | 蛇 | 火 | 丙戊庚 |
| 午 | 马 | 火 | 丁己 |
| 未 | 羊 | 土 | 己丁乙 |
| 申 | 猴 | 金 | 庚壬戊 |
| 酉 | 鸡 | 金 | 辛 |
| 戌 | 狗 | 土 | 戊辛丁 |
| 亥 | 猪 | 水 | 壬甲 |

藏干顺序按常见本气、中余气列示，藏干力量仍需月令及原局分析。本表与三合等基础关系需在上线前逐项锁定所选流派口径。

### 7.2 三合取象候选

| 三合结构 | 象征目标五行 | 已见两支时的第三支候选 |
|---|---|---|
| 寅午戌 | 火 | 寅午 -> 戌；寅戌 -> 午；午戌 -> 寅 |
| 亥卯未 | 木 | 亥卯 -> 未；亥未 -> 卯；卯未 -> 亥 |
| 申子辰 | 水 | 申子 -> 辰；申辰 -> 子；子辰 -> 申 |
| 巳酉丑 | 金 | 巳酉 -> 丑；巳丑 -> 酉；酉丑 -> 巳 |

没有对称的“三合土局”，不得为了凑齐五行编造一组。三会寅卯辰木、巳午未火、申酉戌金、亥子丑水，若使用则与三合分字段处理。

真实干支有三支，不等于无条件合化；图像补出第三支更只能标记为“三合取象”，不能写回真实命盘或用于重新计算强弱。

例：原局戌、流年午，用户火为第一喜用，虎为寅午戌的取象候选。虎本气为木，其选用理由是补全火局的象征，而不是“虎本身属火”。

若只有原局戌与流年午，该候选在整年可能一直成立。要产生每日差异，还须考虑流月、流日与目标变化；不应声称仅由流日选出。

### 7.3 六冲与六合候选

| 真实命盘发现的冲 | 与第一支六合的候选 | 与第二支六合的候选 |
|---|---|---|
| 子午 | 子丑：牛 | 午未：羊 |
| 丑未 | 子丑：鼠 | 午未：马 |
| 寅申 | 寅亥：猪 | 巳申：蛇 |
| 卯酉 | 卯戌：狗 | 辰酉：龙 |
| 辰戌 | 辰酉：鸡 | 卯戌：兔 |
| 巳亥 | 巳申：猴 | 寅亥：虎 |

上表只产生取象候选，不能直接输出“化解成功”。寅申冲选择巳时，可能同时引入寅巳申刑的象征冲突；巳亥冲选择寅时，也须审寅巳关系。六合也可能合绊所需之神，不能把合一律判为好。

冲突检查至少包括：候选支与原局及岁运各支的六冲、刑、害、破，是否象征性合走关键财官印食，是否指向明确不宜五行。采用哪些关系、是否要求三刑齐全、远近与层级如何计权，均须列为流派参数。

重要：图像候选的冲刑检查是产品内部的象征一致性约束，不证明佩戴某生肖会带来现实伤害。不得对用户宣称“戴错生肖会出事”。

### 7.4 候选排序建议

1. 排除用户不接受的动物、宗教元素及无法清楚显示的方案。
2. 排除与主喜用及关键结构明显矛盾的取象候选。
3. 优先与主喜用相符的三合取象，其次次喜用。
4. 在有效候选中，比较是否回应近期目标与当日实际触发的结构。
5. 六合取象和直接五行生肖取象作为其他候选，需通过同样冲突检查。
6. 无合适生肖时使用非生肖意象，不强行给每个人每天配动物。

这一排序是待用户审核的产品方案，不是原典统一规则。

## 8. 所求方向与十神

传统六亲口径中，男命常以财看妻，女命常以官杀看夫，但不能把所有用户的感情目标自动等同于财或官，也不能由此预测现实伴侣行为。

传统框架候选：

- 感情：配偶星、日支夫妻宫及其关系；按用户确认的传统口径配置，不推断其性取向。
- 财富：财星及食伤生财，但先看能否任财、财是否生杀坏印。
- 事业：官印、食伤表达、财务经营等不同路线，按目标细分。
- 学习：印与食伤的理解、输出路线，偏印妨食须审。

目标只能在通过命理条件的候选中排序。例如求财但身弱财重，不能因用户求财就继续以财为主要取象。若目标星与喜用冲突，采用支持该目标所需能力的文化画面，明确不宣称已强化目标星。

## 9. 配色与最终设计输出

木取青绿、火取赤红、土取黄、金取白及金属视觉、水取黑及深色水纹，可作为产品的文化配色方案。颜色深浅、比例和图像样式属于设计参数，不是命理规定。

有限色屏须做适配：四色设备不能真实显示全部青绿与蓝，也没有金色金属光泽；可用轮廓、纹理与少量可显示色表达。主次喜用不保证主辅色均可原样显示。

单次推荐需要输出：

- 原局主次喜用与其审核版本。
- 当前大运、岁月日及来源时间。
- 已触发的传统规则与未满足的条件。
- 产品排序依据和人工复核状态。
- 生肖或非生肖主意象、主辅配色、构图。
- 真实干支关系与图像取象关系分别列出。
- 用户解释采用“依据某传统意象，为你的某目标设计”；不采用“已化解冲煞、保证招财招桃花”。
