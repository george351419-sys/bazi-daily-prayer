# 输出与验收

## 面向用户的两层解读

默认先展示用户解读，随后附专业解析；支持折叠的界面将后者放在“查看专业解析”中，纯文本界面用分隔线与明确标题顺序呈现。用户明确只要结论或只要专业依据时，按其请求调整，不强制重复两层。

### 第一层：用户解读

用户解读固定包含“整体画面解读”和“逐项要素解读”，最后给一句祝愿及必要前提。

整体先用简短文字说明回应的愿望、画面整体氛围与希望表达的祝愿，让用户先看懂结论。

再按实际画面逐项解释可辨的主尊、主辅色、天干意象、选配生肖、背景、台座与其他主要装饰。每项说明“画面中是什么→为何选择/有何设计作用→回应怎样的愿望”，使用短段、列表或表格。相关小细节可合理合并，不必为每一条衣纹单列。未出现的要素不编入解读；已生成图片以视觉核对结果为准，生成偏差不能被解释成原先已经选定的命理元素。

区分个性化映射与普通美术设计：例如银白珠饰可解释辛金象征与和谐祝愿；台座、留白、金线若仅为构图装饰，就说明稳定视觉、突出主体或增加温暖层次，不临时编造补土、补金、护财阵等命理作用。没有生肖不强行把衣纹、云纹解释成动物。无需逐一解释未采用的候选，除非它影响理解。

用熟悉的话表达“生长、经营、和谐、明辨”等设计寓意，避免F/G/T、干支ID、needs_review、争合枚举和缓存信息。没有算出当天独有依据时，不把长期取用或轮换说成“今天独有的运势”。不以“你今天容易破财”等断语解释设计，也不把五合说成真实化解。寓意与实际作用区分，例如银饰“寄托协调与和谐的祝愿”，不说“已化解你的冲”。

专业层有未审定前提时，用户层仍要用一句自然的话标明重要限制，如“这版先按木为主、火为辅的方向设计，配色取用仍待复核”；不能把决定主尊和色系的初判伪装成定论。内部状态不逐项堆在用户层。

### 第二层：专业解析

按实际推导提供：排盘口径与时间→原局及运年月日→取用前提及置信状态→愿望与主尊选择链→色系→天干解冲/调候与无限份覆盖→地支与生肖→未决项、引用及交付状态。保留真实计算、产品规则、文化延伸的区别，并说明未采用候选的原因；不把没有执行的搜索或检查写成已完成。

两层共享同一最终映射记录。用户层提到的主尊、颜色和装饰必须已被选定；不能把专业层的待审甲木候选写进用户层的最终画面，也不能只在专业层更换主尊。专业解析可以折叠，重要限制仍须在用户层保留。完整输入、版本、候选等结构化审计记录另存，不需要在用户界面原样展示字段名。

## 映射记录

每次保存以下字段，未知用null并说明，不填貌似真实的占位日期、分数或干支：

| 字段 | 必要内容 |
|---|---|
| versions | skill、历法工具、命理口径、内容库版本 |
| input | 出生资料、时区、历法、目标日、愿望、偏好、设备、假设 |
| calendar | 原局、大运、流年、流月、流日，各自有效期、换日及交运口径、核验状态 |
| favorable | 身强弱前提及来源、F/G/T条件、主次喜用、人工复核项 |
| actual_relations | 有效合、成员实例、齐全/成局/合化区别、已抑制冲、残余刑冲害、争议 |
| theme | 愿望ID、当日角度、B/D差异、主辅主题、候选及排除理由 |
| deity | 身份、体系、传统关联/现代延伸、该愿望专属理由、来源、固定造像、历史检查、方位名单版本、喜用匹配及轮换让位理由 |
| stem_mapping | 冲表与实例、现有五合、调候条件、豁免来干、解冲候选、无限份策略与全量匹配覆盖及象征复核、后续调候意象、阶段状态与待审项；详见个性化与天干规则 |
| zodiac | 选定生肖、响应关系、象征模型复核、未选原因、搜索上限、待审项 |
| visual | 主辅五行色系及具体色板ID/色值、材质与轮换理由、中性色、天干景物、色板限制、构图、可选祝愿、完整生图提示词 |
| delivery | mapping_only/draft/generated、图片及提示词路径、缓存、重生成理由、实机核验状态 |
| user_explanation | 第一层：整体画面解读＋实际要素逐项解读＋祝愿及重要前提；标明文化取象与美术装饰区别 |
| professional_explanation | 第二层专业解析：排盘、取用、主尊/配色/天干/生肖依据、来源、未决项；界面支持时折叠显示 |

每个冲突保存成员实例及是否被哪个合抑制；每个候选保存新增合、减少及新增的残余关系、喜用作用和采用/排除依据。不得给所有用户套同一句具体干支解释。

缓存使用内部用户ID、目标日和时区、输入版本、评估时刻、规则与内容版本（含天干、主尊排序及色板版本）、偏好及设备参数；不以完整生日明文命名文件或缓存。节气、交运、输入修订按记录口径使缓存失效；按日固定时明确选用日内哪个评估时刻。

## 本项目画风偏好

用户于2026-10-16提出：图片生成可以参考宫崎骏的画风。后续生成默认参考其温暖手绘动画感：柔和自然光、富有呼吸感的天空与云层、细腻手绘背景、清朗舒展的空间，以及温柔、宁静的情绪。按每次映射保留对应色系，不把森林、蓝天、水面等风格联想自动当作新增的木水天干取象。

主尊可采用与整体协调的手绘动画表现，但保持庄重、可辨的身份与核对后的固定造像；不自动改成Q版儿童，不借用现有动画角色充当主尊。额外选配生肖仍遵循可爱Q版规则。风格不能覆盖固定身色、法器、坐骑，也不能增加未选生肖、天干意象或改变数量。无需为了贴合画风强加森林、河流、动物或精灵。

此前唐卡式矿物色、密集金线不再是默认整体风格；仅在用户明确需要或本次画面选定时保留相应细节。画风变化不改变命理映射，主尊、配色、辛金珠饰等选定元素在新画风中重新表达。设备色板与小屏可读性照常检查。

## 提示词模板

出现选配生肖时明确要求Q版可爱造型：大头短身、圆耳或其他物种识别特征、短肢、圆润轮廓、友善表情，小屏清晰可辨；避免写实动物。主尊保持庄重，不随生肖一起卡通化；固定坐骑不因这条要求自动改造。

单张平面祈愿画，适配{尺寸比例}。参考宫崎骏作品的温暖手绘动画感，柔和自然光、细腻手绘背景、舒展留白与宁静氛围；主尊庄重且身份清晰。中心为{主尊及核对的固定造像}，主题{愿望与当日角度}。背景及装饰用{主色}、{辅色}，保留固定身色、手印、法器及坐骑。{有生肖时明确种类数量与次要位置；无生肖时禁止额外添加生肖。} {已选天干对应景物及其位置；无选项时不擅加天干象征。} 轮廓清晰、主体突出、小屏可辨，不堆叠细碎纹样。不含伪经文、伪咒语、商标、水印或功效宣称。{色板与概念图限制。}

生图提示词不含完整出生资料，不承诺今天发财、实际消冲等结果。生成后检查身份、坐骑、生肖、数量、天干意象和色彩；错误则修改再试，无法核对标草稿。生成工具与输出路径记入交付记录；概念图不等于实机已通过。

## 行为验收

以下是规则演练，不是命理功效实验；合有效条件为用例明确假设，不用假设反证合必然成立。人工逐项检查即可；未来实现关系引擎时转换为断言测试。

| 用例 | 条件 | 应得结果 |
|---|---|---|
| 已合不补 | 实际寅午戌有效，喜火，无其他残余 | 生肖空；不再补虎马狗；涉及该寅的寅申冲标被合抑制 |
| 仍有残余 | 上例另有未处理关系 | 仅为残余检索候选，不为已有火局补生肖，不预设必有解 |
| 候选也先合 | 候选形成有效合，成员原本参与冲 | 不以该已抑制冲否决候选 |
| 合失效 | 新状态下原合失效 | 释放实例并重新检查冲 |
| 同支不合并 | 两个寅，仅一个参与合 | 不自动锁定另一个寅 |
| 刑害不自动删除 | 合成员仍涉及刑害，无确认解除规则 | 保留或标不确定 |
| 喜用前提 | 用户指定己土身弱印比 | 火印土比为本次前提，不沿用旧例水金，不泛化所有己土 |
| 多愿望 | 财源广进、升职加薪、创业顺利；实践角度适配 | 普贤可为创业现代延伸，不称创业专职神 |
| 输入不足 | 缺时辰或交运不明 | 不默认中午、不猜大运；问关键项或降级 |
| 候选无解 | 没有净改善组合 | 空集或needs_review，不无限补生肖 |
| 固定坐骑 | 普贤白象，生肖空 | 白象不算生肖，不被错误删除 |
| 最强非最宜 | 财突出但不宜增强 | 不自动推荐求财或投资获利 |
| 地支竞争合未定 | 共享地支成员且无明确取舍条件 | 分支或求审，不自定绝对排序；不用于否决无限份新增天干 |
| 新增天干无限份 | 新增辛、已有原局及运年多个丙 | 同时记录全部辛丙象征五合，一个辛意象即可，不按多干争合送审 |
| 要素解读覆盖 | 图片含主尊、青绿云纹、暖霞、银白珠饰、台座及金线 | 先整体后逐项；珠饰说明选用寓意，台座金线只讲实际美术作用，不编命理功效 |
| 两层解读一致 | 专业层已选辛、甲仍待审 | 用户层可解释银饰寓意，不把甲树写成已选；取用初判须自然提示 |
| 日历边界 | 节气或交运边界 | 核对目标时区及具体时刻，不按整年标签猜大运 |

## 示例边界

庚午、戊寅、己酉、壬申，用户确认按身弱印比、火主土辅，愿望W02/W09/W10。核对目标日的运年月日、确认有效火局后才可说无需补虎马狗，仍检查其他残余关系。可选普贤表达创业实践，注明现代延伸，并从来源清单核对实际来源编号。暖红背景、黄色莲台、白象固定坐骑；若无其他可改善关系，生肖为空。本例不是完整自动排盘结论，不能直接复用为别的日期方案。

## 能力范围

这是助手工作流与参考包，不是已实现的确定性命理引擎。历法可用排盘工具；旺衰量化、会合有效性、竞争合排序、解刑解害条件须按审定规则或人工审核执行。未审定不假装全自动。素材商用授权、固定造像审核、电子墨水色彩量化及实机验收分别记录未完成项。
