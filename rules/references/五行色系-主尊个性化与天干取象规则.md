# 五行色系、主尊个性化与天干取象规则 v1.1

日期：2026-10-16。落实用户本轮三项优化。本文件与关系规则优先于早期审阅稿的单色、五行仅同等排序和仅地支优化表述。它是产品规则，不表示已经实现自动命理引擎。

## 1. 五行对应色系，不限定单色

| 五行 | 可选色系 | 画面表现 |
|---|---|---|
| 木 | 青绿、翠绿、嫩绿、墨绿、松绿、蓝绿色中的偏绿色 | 草木、叶纹、青绿云饰 |
| 火 | 赤红、鲜红、朱红、橙红、绯红、暖橙 | 日光、霞光、暖色光晕 |
| 土 | 土黄、赭黄、米黄、沙色、棕褐 | 山石、地景、台座、稳定块面 |
| 金 | 白、象牙白、金黄、香槟金、银、银灰 | 金银线、金属纹理、清晰轮廓 |
| 水 | 黑、墨色、藏蓝、深蓝、靛蓝、湖蓝、浅蓝 | 水波、流线、深浅蓝色空间 |

色表是用户认可方向的产品设计扩展，不把每个色名包装成古籍定论。金黄色可表达金属金，也可能接近土黄；以所选色板ID、材质、场景与设计意图区分，不仅凭像素色值判五行。蓝绿交界同理。

主喜用选择主色系，次喜用选择辅色系；在色系内按用户审美、愿望情境、对比度及近期配色轮换。没有可靠次喜用时用中性色，不制造第二喜用。记录element、palette_id、具体色名/色值、用途、材质、选用理由及设备替代。

颜色作用于可变背景、云纹、台座、边饰；不覆盖主尊固定身色和造像。金银在普通显示屏上是材质模拟；有限色屏缺色时记录替代或量化状态，不把金色光泽视作已经可显示。色系轮换保持主次喜用，不能为了每日不同切换到无依据的五行。

## 2. 主尊：愿望准入后，优先喜用匹配，并约束重复

先尊重用户明确指定的主尊、文化体系及禁用项，再用愿望专属理由、当日表达角度与造像审核筛出相关候选。暂停关联不能因五行合适重新进入候选。

在符合愿望与角度的候选中，有来源且明确登记的五行映射优先：主喜用匹配 > 次喜用匹配 > 无五行标签的相关候选。没有合理五行标签不等于不适配，更不能给神佛临时编五行。较弱的辅助关联不因五行标签压过明显更切题的主体。

轮换开启时，先检查昨天展示：有其他合格候选就避免连续同尊，再在可用候选中按喜用匹配、愿望贴合程度及距离上次展示时间排序；同档用可复现用户/日期种子选择。避免连续同尊是产品默认，用户指定常驻或仅剩一名合格候选时允许重复；不设置无依据的冷却天数或分数。轮换关闭时保留最适配主体。记录因轮换从主喜用候选切换到次喜用或其他相关候选的理由。

## 3. 天干独立层：解冲 > 调候，保留调候例外

此优先级仅用于天干象征元素的选择，不取代整体喜用的“扶抑 > 格局 > 调候”，不重算原局喜用。图案不进入实际命盘，不能称实际合化或已经解冲。

### 3.1 实例、冲与五合表

扫描原局＋大运＋流年＋流月＋流日的天干实例，重点处理至少一端为原局四干的冲。运岁月日冲原局时，记录原局受冲干和外来干；原局内部冲独立记录，不虚构外来方向；纯动态层之间的冲保留背景记录，不自动扩大本轮保护范围。

本版采用常见四组作为明确的产品检测表：甲庚、乙辛、丙壬、丁癸；双向识别。此表不是所有天干相克表，戊己不因此被编入第五组冲。不同流派若需改表，保留版本。

| 乙 | 庚 |
| 丙 | 辛 |
| 丁 | 壬 |
| 戊 | 癸 |
| 己 | 甲 |
| 庚 | 乙 |
| 辛 | 丙 |

甲己合土、乙庚合金、丙辛合水、丁壬合木、戊癸合火仅登记为条件性化气目标；五合配对、有效合绊、合化分别存储，不见两干即认定化气。实际模型每个天干带唯一来源ID，同名干不合并，实际五合条件仍按原口径记录。

象征模型采用用户确认的“新增天干无限份”规则：新增干类型可同时参与与全部已有天干的五合，对每个匹配实例视为有独立的一份，不存在新增干份数不足或多干争合。无需在原局、大运、流年、流月、流日之间争夺一个新增干；同一种干在画面上只需一种清晰意象，不按匹配数量重复绘制。适用范围是本次天干优化新增的干，不扩展为地支生肖无限份，也不把实际天干改成无限份。新增干匹配原局日干时一并记录，不仅因同时匹配多个丙等现象否决候选；匹配全量参与与是否合化、是否影响关键用途分字段，不自动断作实际日干被合走。

### 3.2 执行顺序

1. 读取经过条件核验的调候所需天干T，保留主次、并用、替代、透藏条件及现有满足情况。索引表中出现过的全部候选不等于本次所需；丙不能因同属火自动替丁。T不确定时不默认为空，也不自动判定“无需保护”。
2. 实际模型A先检查现有有效五合、实例分配与仍有效的冲。已有效合绊而按选定口径抑制的冲保留证据，不重复为它加元素；无审定有效性或抑制规则时标needs_review，不凭配对齐全直接判断已解。天干和地支规则独立执行，不能把地支的有效合证据直接挪到天干。
3. 对动态干冲原局的残余关系，若来冲的具体干为本次T所需，跳过针对该来干的解冲，标skip_for_required_tiaohou；不为消除这条冲把调候所需合走。是否确为所需尚有条件争议时保留分支。原局内部冲无明确“来冲者”，无确定选边规则时复核，不任意选择。
4. 对非豁免的残余冲，优先提出“来冲干的五合对象”作为象征候选。例如原局甲受庚冲，先评估乙合庚；原局庚受甲冲，先评估己合甲。不能默认采用受冲原局干的五合对象，以免合绊要保护的原局干。候选若伤喜用、绊住所需调候干或破坏关键结构则排除/复核。
5. 在象征模型S中联合复核全部候选：按无限份规则展开每一种新增干与全部已有匹配天干的五合，记录covered_instance_ids，不进行排他分配，不因多干争合送审。解冲候选可按此产品规则记录为已建立五合象征响应；不据此认定实际命盘已经解冲或合化。继续核对新增冲、明确的关键用途冲突、调候保护及与地支方案的兼容；其他未定条件仍分别记录，不能把份数不足作为不确定项。对多条冲同时评估，按新增干类型去重，同效选择最少意象，不需要画无限多个图案。
6. 无残余冲，或非豁免冲已通过所选规则得到象征响应后，再评估调候所需且尚缺表达的天干。仅有豁免冲时可进入调候；不得因图面还有豁免冲就重新合走所需干。已有符合条件的调候支持或候选同时承担两项用途时，不再重复添加。并用要求整体核验，不能单加一干就称组合已满足。
7. 非豁免冲未处理、无合格方案或条件未定时，保留已审定方案/无天干附加元素及needs_review，不用调候装饰冒充已经完成前序解冲，也不承诺所有冲都能解决。

“无冲/已响应”的判定只涉及本层范围和所选规则，不表示全盘没有刑冲，也不表示现实问题已经消除。调候本轮例外只保护具体所需干，不扩成所有同五行来干都免处理。

### 3.3 天干 → 独立意象（产品设计候选）

以下为可区分阴阳干的首版象征词汇，作为产品延伸，不视作自然景物对某干的唯一传统归属，也不代表图片实际新增天干。场景模板需记录具体干标签，不以颜色反推天干。

| 天干 | 可选意象 | 表达区分 |
|---|---|---|
| 甲 | 挺拔乔木、树干、林木 | 生长、挺立 |
| 乙 | 藤蔓、柔枝、花草 | 柔韧、舒展 |
| 丙 | 太阳、日轮、开阔日光 | 明朗、温暖 |
| 丁 | 灯火、烛光、局部暖光 | 专注、细暖 |
| 戊 | 山峰、山岩、厚重地景 | 稳定、承托 |
| 己 | 田园、沃土、柔缓土地 | 培育、承载 |
| 庚 | 金属几何边饰、坚实金属纹 | 刚健、有序 |
| 辛 | 珠玉、精细金银饰、晶莹纹样 | 精细、清明 |
| 壬 | 江河、海面、连续水流 | 流动、开阔 |
| 癸 | 雨露、水滴、细润水纹 | 润泽、细微 |

选择与主尊造像不冲突的背景/边饰表达：不把太阳擅称主尊固定日轮，不给主尊新增法器，不将金属意象默认变成武器。火主色仍可搭乙木藤蔓来表达乙合庚：总体色系与天干景物各有依据，无需把解冲候选升级为第二喜用。若调候意象与总体喜用/固定造像无法协调，标冲突待审，不悄悄改主辅色。

## 4. 输出、缓存与行为验收

新增stem_mapping，保存scope、冲表版本、实际冲成员与来源、现有五合与有效证据、T及条件、豁免理由、候选干/目标来干、symbolic_copy_policy=unlimited、每类新增干的全部五合匹配实例及coverage、减少及新增冲、关键干保护、解冲与调候阶段状态、意象模板及待审项。actual_relations与symbolic_relations分开，五合不回写calendar。visual保存色系及具体色板；deity保存方位版本、喜用匹配与轮换原因。

联合画面复核主尊、色系、天干意象、生肖数量及可读性；输出用户解释时可以说“以藤蔓意象回应本次乙木取象”，不能说“已替你加入乙木，现实冲突已解除”。更新规则与色板版本使旧缓存失效；历史样例不追改成已经采用新规则。

| 场景 | 应得结果 |
|---|---|
| 火为主喜用 | 可在朱红、鲜红、橙红等火色系中选，不强制赤红 |
| 金为主喜用 | 允许金黄、银色及白色，保留材质与土黄区别 |
| 水为主喜用 | 允许蓝色系，不强制黑色 |
| W02单尊、喜火木、昨日未展示陈九公 | 在准入和造像条件通过时优先陈九公，萧升次选 |
| 同上、昨日陈九公、轮换开启 | 评估萧升等合格备选，记录轮换让位理由 |
| 用户固定关公 | 保留指定主体，不因喜用强换五路财神 |
| 原局甲、流日庚、庚非调候所需 | 优先评估乙合庚，不能直接判已化金或已解冲 |
| 原局甲、流日庚、庚确为调候所需 | 豁免合走庚，进入后续调候需求检查 |
| 调候需丙、来干壬冲原局丙 | 评估丁合壬；壬不因属水或参与调候组合的未审候选自动豁免 |
| 没有目标冲、调候缺丙 | 通过条件复核后用日光意象；红背景本身不能算已补丙 |
| 解冲候选已经表达了所需调候干 | 记录双用途，不重复堆元素 |
| 来冲干是否调候所需未定 | needs_review，保留分支，不擅自合走 |
| 两个庚需要乙合 | 新增乙视为无限份，同时匹配两庚；一个乙木意象即可，不因争合送审 |
| 原局丙、大运丙、流年丙，新增辛 | 辛与三个丙均建立象征五合记录，不争夺一辛，不因匹配日干直接否决 |
| 新增辛同时遇到已有乙 | 无限份只处理五合可复用性，辛乙新增冲仍须检查 |
| 地支生肖候选 | 不套用天干无限份，继续原地支实例与成员分配规则 |
| 非豁免冲无合格响应候选 | 保留未解决状态，不假称已解后继续调候 |
