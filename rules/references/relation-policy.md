# 会合优先与生肖取象规则 v1

## 关系与参数

本规则为用户指定的产品口径，不代表流派共识。真实排盘解释与图案象征模型采用同一顺序，但分别保存，不互相写回。

| 类型 | 关系 |
|---|---|
| 三合 | 寅午戌火、亥卯未木、申子辰水、巳酉丑金；没有三合土局 |
| 三会 | 寅卯辰木、巳午未火、申酉戌金、亥子丑水 |
| 六合 | 子丑、寅亥、卯戌、辰酉、巳申、午未；目标五行与化气条件逐条审核，不默认皆化 |
| 六冲 | 子午、丑未、寅申、卯酉、辰戌、巳亥 |
| 六害 | 子未、丑午、寅巳、卯辰、申亥、酉戌 |
| 刑 | 寅巳申、丑戌未、子卯；自刑辰辰、午午、酉酉、亥亥 |
| 生肖 | 子鼠、丑牛、寅虎、卯兔、辰龙、巳蛇、午马、未羊、申猴、酉鸡、戌狗、亥猪 |

三刑是否须齐三支、两支是否论刑、自刑条件是待固定参数；不以表格代替成立条件。破仅在明确启用且确定口径时补充检查，不扩展为所有破必须消除。

用户只确认三合、六合、三会先于残余冲突处理，尚未确认三类合发生竞争时的绝对排序。不得擅自写死“三会永远大于三合”等规则。有共享成员的关系必须分配或保留分支；无明确条件可决出时标needs_review，不同时采用互不兼容的合。

## 实例与贪合忘冲

每个支有唯一来源ID，如natal.month.branch、transit.day.branch。两个午不是一个午；不去重、不将同名支全局锁定。每个合分别记录成员、齐全性、有效牵合、成局、合化、条件证据、喜用作用和是否采用。

三支齐全、有效牵合、成局、合化不能互换。采用合优先的门槛是依选定条件确认的有效牵合，不要求一律证明合化，但不能只凭成员齐全自动认定。

先分配有效合，再计算冲：一个冲的任一成员实例已参与当前采用的有效合，该冲就标记suppressed_by_binding，不作为残余、不扣分、不再为它配生肖。保留原始冲及抑制它的合供审计，不删除历史记录。

有效但不利的合，也可能牵合；合是否有效与合出五行是否为喜分开，不为迎合喜用否认有效性。刑、害不因合自动删除，只有已确认的解刑/解害规则才可标缓解，否则保留或标不确定。状态改变使合失效时，释放实例并恢复冲检查。

## 两遍判定与有界搜索

1. 实际模型A：原局＋运＋年＋月＋日。先判有效合及成员分配，再算残余冲、刑、害。
2. 已有完整有效有利组合不触发补成员。继续检查其他残余关系，不能因已有三合就停止。
3. 为残余关系或尚缺的有利组合提出候选。反查六合对象、三合/三会缺项，注明欲响应的关系；不以生肖本气冒充合局目标五行。
4. 象征模型S：复制A并加入symbolic.*候选实例。每组都从头求合及其分配，再查残余冲突；不冻结A的旧分配，不直接累加所有原始冲。
5. 对比S与A：是否保留关键有利关系、符合喜用、缓解目标残余关系、引入新的剩余刑冲害。被抑制的冲必须有具体有效合证据。不得把S结果回写A或宣称图像改变真实命盘。
6. 先排明显破坏关键关系或违背喜用者；其余按残余改善、主次喜用、当日愿望与可读性比较，同效取最少生肖。无权重时定性说明，不编化解率。

初版枚举空集、12个单生肖、66个双生肖组合，明确需要时再扩展三生肖。数量上限是小屏与计算的可调参数，不是传统禁忌。对完整组合一次性评估，不逐个补到无限循环。无净改善时用空集或人工复核，不承诺所有冲突有解。

喜用、合有效性或竞争规则未定时标needs_review，可给带假设候选，不能冒充已实现的全自动确定结论。

## 本例

男命庚午、戊寅、己酉、壬申；按用户指定身弱印比，火主土辅。大运与流年月日依目标日期核对，不把截图高亮运永久沿用。

若实际模型已确认寅午戌有效合，不再补虎马狗，也不把该已合寅参与的寅申冲计为残余。另有刑害仍查，不预设有或无。普贤白象为固定坐骑，不计生肖。
