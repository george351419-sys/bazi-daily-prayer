# 今日祈愿 · 微信小程序设计与实现规划

2026-10-29。目的：手机端管理桌面墨水屏；随时看图、读行动、查答案。首屏优先呈现图文融合画面，硬件进度只基于实际回执。

风格：纸本画册（Editorial / Organic）。纸白 #F6F1E7、墨 #272E28、松绿 #415B48、朱砂 #A44B3F、暖灰 #8B877B。标题优先 Songti SC、Noto Serif CJK SC、serif；表单正文 PingFang SC、Microsoft YaHei、sans-serif。原生平台正文清晰度优先于 web skill 禁用系统字体的默认建议。无外部字体下载，无 emoji 图标；使用文本自定义 tabBar。

布局：左对齐章节编号与标题；竖画右上角叠印章；底部动作区与画面共用纸白留白。显示比例 2:3；图片采用 contain 保留完整构图，不用 cover 裁切。动作区在有动作时出现，个人照片可关闭。图像色彩仅做网页/小程序预览，实际六色上屏依固件。

四个底部一级页面与“答案之书”二级页面：
- 解读陪伴：当前画面，以及画面解读、微行动解读、答案之数解读三块内容；答案可在手机翻页或查看全部100条。未登录展示明确标注的示例，不伪造设备在线状态。
- 许愿池：只负责账户、生辰、心愿和生成今日祈福画；生成后引导到解读陪伴，不在此页重复展示图画解读。
- 自定义：先上传个人图片，可一次多选；最多 6 张按顺序每日 01:00 循环。支持加入已有图片、上移/下移、移除、微行动开关、确认切换、保存更新与切回祈福图。
- 答案：100 条原始内容，随机翻一页、关键词或编号搜索、展开解读。随机答案明确为手机抽取，不写成设备按钮回报。
- 我的：微信一键登录并自动建立免邮箱账户、已有网页账户低调入口、微信绑定、昵称与生辰祈愿编辑、退出、隐私说明。

数据方案：沿用 playmath.cn EdgeOne HTTPS API、账户与私有图片；不新增 CloudBase。用户点击登录后，客户端调用 `wx.login` 并通过固定 HTTPS API 提交临时 code；服务端使用只存在环境变量中的 AppSecret 换取 `openid`，建立或进入账户。服务端不保存 `session_key`，账户记录只保存身份摘要。旧账户可主动绑定微信，冲突时拒绝自动合并。客户端显式保存账户会话 cookie，密码不落盘；只发送到固定的 playmath.cn。请求保留 session+CSRF；服务端按配置的正式 AppID 验证微信 Referer，默认不开放任意小程序。

设备模型：画屏成员与账户数据分离。同一画屏可由家庭内多个微信账户关联，但只有一个当前下发账户，避免并发计划互相覆盖。切换时用户在附近重新完成蓝牙连接并确认；未激活账户仍可查看自己的资料，但不会向画屏下发。

照片：用户主动同意隐私后选择，可一次多选；相册/相机 → 逐张本地 Canvas 重绘 JPEG（剥除 EXIF）→ 最长边 1440 → 不超过 768 KiB → 私有账户。轮播列表最少 1 张、最多 6 张，顺序决定每天显示哪一张；删除只从轮播移除，账户画册原图仍保留。不调用付费模型。蓝牙 Wi-Fi 密码仅发给所选 FRAMEFILMARK 外设；不存储、不上传服务器，页面离开清空并断开；必须读回 SSID 与 Wi-Fi 状态确认。

测试：两日各八个动作，每 120 秒切换，一日结束后换第二幅，32 分钟循环。前台定时刷新，后台停止；设备时间与网页计划分别标识。仅有 EdgeOne 的现状下，内容编译/自动下发未接通，保存仅表示账户计划保存。

交付顺序：原生源码与可交互设计预览 → 单元/契约/编译检查 → 正式账号 AppID、开发者扫码登录、合法域名/隐私/备案及类目确认 → 真机微信登录、蓝牙与照片验收 → 上传体验版 → 微信审核 → 发布。没有服务端 AppSecret 与真机登录不得声称微信登录已上线。宗教造像/生辰解读须根据实际业务在微信后台核验服务类目、资质与内容要求；不得通过改名隐藏功能绕过审核。
