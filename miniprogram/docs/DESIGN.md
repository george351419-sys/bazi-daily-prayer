# 今日祈愿 · 微信小程序设计与实现规划

2026-10-29。目的：手机端管理桌面墨水屏；随时看图、读行动、查答案。首屏优先呈现图文融合画面，硬件进度只基于实际回执。

风格：纸本画册（Editorial / Organic）。纸白 #F6F1E7、墨 #272E28、松绿 #415B48、朱砂 #A44B3F、暖灰 #8B877B。标题优先 Songti SC、Noto Serif CJK SC、serif；表单正文 PingFang SC、Microsoft YaHei、sans-serif。原生平台正文清晰度优先于 web skill 禁用系统字体的默认建议。无外部字体下载，无 emoji 图标；使用文本自定义 tabBar。

布局：左对齐章节编号与标题；竖画右上角叠印章；底部动作区与画面共用纸白留白。显示比例 2:3；图片采用 contain 保留完整构图，不用 cover 裁切。动作区在有动作时出现，个人照片可关闭。图像色彩仅做网页/小程序预览，实际六色上屏依固件。

四个一级页面：
- 今日：当前画面、当前动作与解读、画面解读、刷新。未登录展示明确标注的示例，不伪造设备在线状态。
- 画屏：原生蓝牙发现/连接/配网、照片上传、两日内容选择、祈福/照片模式、动作开关、测试/日常播放。
- 答案：100 条原始内容，随机翻一页、关键词或编号搜索、展开解读。随机答案明确为手机抽取，不写成设备按钮回报。
- 我的：登录既有网站账号、注册及恢复码展示、生辰和祈愿编辑、退出、隐私说明。

数据方案：沿用 playmath.cn EdgeOne HTTPS API、账户与私有图片；不新增 CloudBase。首版保留同一账户密码，微信免密与账号绑定留待正式 AppID 与服务端凭据就绪后实现；不伪造 wx.login 成功。客户端显式保存账户会话 cookie，密码不落盘；只发送到固定的 playmath.cn。请求保留 session+CSRF；服务端按配置的正式 AppID 验证微信 Referer，默认不开放任意小程序。

照片：用户主动同意隐私后选择，相册/相机 → 本地 Canvas 重绘 JPEG（剥除 EXIF）→ 最长边 1440 → 不超过 768 KiB → 私有账户。不调用付费模型。蓝牙 Wi-Fi 密码仅发给所选 FRAMEFILMARK 外设；不存储、不上传服务器，页面离开清空并断开；必须读回 SSID 与 Wi-Fi 状态确认。

测试：两日各八个动作，每 120 秒切换，一日结束后换第二幅，32 分钟循环。前台定时刷新，后台停止；设备时间与网页计划分别标识。仅有 EdgeOne 的现状下，内容编译/自动下发未接通，保存仅表示账户计划保存。

交付顺序：原生源码与可交互设计预览 → 单元/契约/编译检查 → 正式账号 AppID、开发者扫码登录、合法域名/隐私/备案及类目确认 → 真机蓝牙与照片验收 → 上传体验版 → 微信审核 → 发布。没有账号不得声称微信上线。宗教造像/生辰解读须根据实际业务在微信后台核验服务类目、资质与内容要求；不得通过改名隐藏功能绕过审核。
