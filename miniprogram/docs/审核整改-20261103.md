# 小程序流程与内容整改

修改目录：`daily-prayer-web/miniprogram`，以及同仓库的 `lib/domain.mjs`、`lib/service.mjs`、`lib/wish-art.mjs`、`lib/accounts.mjs` 和 `lib/automation.mjs`。

## 行为

- 首页直接展示祈愿、画风与示例，浏览和选择不调用微信登录，不上传个人资料。
- “个性化设置 · 生日纪念”默认折叠、可选、可清除。选择生辰个性化时仍须真实日期和时刻；未提供时不补造日期和时刻。
- 点击生图、完成祈愿和画风选择后才出现自愿登录入口。登录同意与取消分开；未同意不调用 `wx.login`。无需手机号、头像或昵称。
- 取消登录、登录失败、切换底部页面后保留本次选择；草稿仅在内存保存，不在同意前写入个人资料。关闭小程序或退出账户会清除草稿。
- 登录成功保留本次草稿，继续生成；不使用登录响应中的旧账户偏好覆盖它。
- 不填写生日时使用显式 `wish-art` 模式，按祈愿和画风生成艺术方案，不排命盘；模式随资料和自动生成快照保存，供后续日期沿用。
- 填写生日时保留原有生辰选图算法；小程序不再展示命盘、运势、吉凶、改运、喜用次数等解读。保留这一算法仍需平台确认可接受，不能把折叠或改名等同于已符合第一条审核要求。
- 陪伴页改为画作欣赏、通用寄语和日常休息建议。答案之数不再注册路由，废弃页面与对应内容库不进入小程序包。网页和画屏固件不在本次修改范围。

## 发布依赖

本次没有部署后端、上传小程序或提交审核。无生日生成依赖同批后端变更；仅上传小程序、继续使用旧后端会收到必填生辰的校验错误。正式交付应先部署兼容 `wish-art` 的后端，再上传小程序，最后进行手机验收和提交审核。不得将代码测试或局部模板编译当作手机或实体画屏验收。
