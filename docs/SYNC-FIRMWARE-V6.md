# ritual.6：同步回执与自适应文字

版本：3.2.5-ritual.6。仅升级应用，不改分区，不自动刷写设备。

- 显式Wi-Fi连接指令0x38重新开启120秒交互同步窗口；首次检查没有新包时继续等待后台发布。蓝牙保持连接时以30秒低频检查，未连接时按原低功耗唤醒策略运行，窗口有上限。
- 保存和驱动刷新流程结束分别唤醒心跳任务，并持有待发送标记。云端持久化收到的回执后返回包SHA和事件序号；设备只清除同包同序号的待办。事件序号和待办保存在RTC内存，跨深睡恢复；冷启动丢失时会安全地重新核验/领取，不伪造成功。
- 心跳失败退避、有限回执窗口，未完成任务下次唤醒重试；不靠无限阻止休眠保证送达。主动休眠和低电量保护保留。
- 后台下载不抢占Home和设置页；确认保存后，网页和小程序提示在画屏选择“画面”并按设备确认键。已在画面页则沿用下载完成事件刷新。
- 网页修正window发事件、document收事件的绑定断链，并对重复设备状态去重。绑定完成后请求设备检查云端。
- 网页和小程序共用状态判定：内容就绪、下载中、已保存可进入、已回报刷新；当前包的成功回执不因设备休眠被抹掉，不把旧包当新包完成。小程序可见时轮询，离页停止；“立即检查同步”需当前蓝牙连接和新固件。
- 微行动先实际换行并测量字形高度，再对固定白底中的文字整体居中；两行增加行距，三行收紧，少数字符落单时适度均衡换行。保持字号，溢出明确失败，不截掉文案。背景图和已保存原始画作不改动；设备内容包的排版版本升级会使Worker重新编译。

183项服务/网页测试通过；小程序测试与语法、路由检查通过。真实离线编译→签名上传→心跳领取→精确下载链路通过。固件同步策略、实际C合成器、落盘/NVS失败回滚、内容替换与回报竞态、休眠和图片事件主机测试通过。ESP-IDF v5.5.2构建和镜像校验通过，应用仍在既有OTA分区内。
