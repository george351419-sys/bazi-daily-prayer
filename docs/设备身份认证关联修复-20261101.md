# 设备身份核验与自动账户关联

旧实现从BLE名称解析12位值。自定义名称无法识别，而且蓝牙MAC与Wi-Fi/云端ID不是同一身份；不能靠广播名或MAC推导来绑定。

新流程：已登录且设备联网时，账户接口签发90秒随机识别码；通过既有0x3F读心跳地址、0x3E临时设置同源认证心跳地址，再用0x38触发检查。设备仍使用其原有Bearer凭据和实际film_device_id。只有认证成功的真实心跳能写入首次身份回报；另一个账户不能查询识别结果。客户端最长等待60秒，结束时恢复标准心跳地址。中途退出留下的临时地址过期后仍按正常心跳处理，不阻断更新。

兼容旧固件拼接规则：固件在base后固定添加?device_id=；临时base以&device_id=结尾，服务端只对格式正确的识别码规范化这项参数。请求大小在原128字节地址字段及已协商MTU内；不读取设备token或Wi-Fi密码，不改固件、OTA入口及凭据。

同版本包含已存Wi-Fi网络名回填、密码遮罩和复用设备中凭据，保留最新生产OTA兼容修复和自动同步逻辑。

验证：隔离生产基线3e93395上213项服务/网页测试、39项小程序测试、语法路由及EdgeOne构建通过。覆盖认证失败不写身份、跨账户拒绝、过期挑战不阻断普通心跳、自定义广播名及恢复心跳地址。未执行真实手机BLE身份核验、真实账户关联或实体画屏显示验收；不得把模拟通过或发布完成当成实体验收。不会自动刷写设备。
