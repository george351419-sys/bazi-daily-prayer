# 先生成内容，再连接画屏

本次将首次使用顺序统一为：许愿池 → 链接神物 → 解读陪伴 → 自定义。

用户先填写生辰与心愿、生成今日画作，再补齐两日画作。编译 Worker 会为尚未绑定设备但已有有效计划的账户执行画屏转换，并上传实际内容分块；只有所有分块保存成功，状态才变为 ready。准备区按实际执行显示排队、读取画作、转换和保存阶段；保存百分比取成功分块数/总分块数，转换阶段没有虚构百分比。

ready 后引导连接蓝牙、Wi-Fi 和绑定账户。Worker 将已保存分块关联到实际绑定设备，不再重新转换或上传图片。绑定前不会给任何设备提交内容；提交前再次验证账户当前计划与绑定。更新计划后旧 ready 状态不能冒充新计划完成，旧任务构建回写按 revision 拒绝。

自定义上传仅保存图片，用户确认切换后才建立播放计划并准备内容包。未绑定用户准备完成后看到连接入口；已绑定用户由画屏联网领取，回报不足时提示唤醒和检查连接。无需每次切换作品都重新填写 Wi-Fi。

小程序使用应用级 BLE 会话，跨页保留连接；内容准备失败可单独重试准备，不必重新生成今日画作。绑定操作不触发新的画作生成。

验证：210 项服务端/网页测试、24 项小程序测试通过；独立集成经过真实 Python 墨水屏转换、未绑定准备、绑定后复用分块提交、模拟设备心跳与下载校验。网页默认页、导航顺序、准备阶段、75% 保存进度、ready 后连接入口及自定义确认路径均已在浏览器模拟验证。微信开发者工具确认默认进入许愿池、页面模板编译及错误日志检查分别记录在本次执行结果中。
