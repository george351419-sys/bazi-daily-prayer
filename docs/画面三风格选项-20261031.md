# 画面风格选择

本次实现可爱风 cute、灵兽风 spirit、民俗风 folk。新生成未指定时默认可爱风，历史图片未标风格仍按民俗风识别；未知值服务端拒绝。

网页许愿池和小程序“我的”生辰/心愿设置提供三个单选项，每项独立“查看示例”，预览不改变当前选择。小程序示例本地打包，网页用静态资源；现有方形样图仅作风格示意，不代表横屏最终构图。

artStyle随分析请求、账户资料和每日生成快照保存。服务端把验证过的选择写入mapping.art_style及art_style_version，不信任模型自行返回的风格值。画面指纹区分风格和布局版本；次日作品和自动轮换检索不跨风格。用户仍可从画册选用已有作品，切换偏好不重绘已有画面。

灵兽风生成通过服务端image参考参数附带用户提供的问问兽三视图；不是只有文字。图片提示词使用横向3:2、720×480目标及底部25%文字覆盖预留，默认向当前图片供应商请求2496×1664横向原稿。普通生成原稿不等于精确720×480成品，设备转换阶段及实机效果须另验；旧ARK_IMAGE_SIZE显式配置优先，需要部署时核对是否仍指定方图/竖图。未进行真实付费模型调用，供应商参考图保真度与实际生成效果仍需后续验收。

示例素材来自本次对话已生成作品，问问兽参考来自用户三视图。生图端不发送完整出生资料。

验证：基于线上最新main（6b8969d）隔离合入；153项Node测试、14项小程序测试与包体检查通过，EdgeOne构建通过。网页此前本地验证三个单选、示例加载、选择与预览分离、Escape关闭及无控制台错误。正式小程序目录WXML、WXSS真实编译通过，2026-10-31以1.0.3上传成功（AppID wx67be26840ab16898）。上传代码不等于审核发布，体验版需以微信后台选定的版本为准。

生产环境已有小程序AppID及微信登录密钥；未显式设置ARK_IMAGE_SIZE，采用横图默认值。源代码通过现有GitHub main集成部署至playmath.cn，不改变生产密钥。
