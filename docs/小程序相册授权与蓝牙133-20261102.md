# 1.1.10 修复记录

用户真机：保存壁纸提示已取消但没有写入相册；安卓蓝牙建立失败截图 createBLEConnection:fail:connection fail status:133。

确认的代码缺陷：requirePrivacyAuthorize 没有配套 onNeedPrivacyAuthorization 和原生 agreePrivacyAuthorization 按钮；旧错误分类把含 privacy 的失败报成取消。现在所有页面挂载统一隐私组件，由用户通过原生按钮同意后恢复原请求。相册保存只有成功回调才报成功，权限拒绝提供设置入口；其他失败保留原因。

蓝牙建立失败发生于手机原生连接阶段，此时尚未执行心跳URL写入或HTTPS请求。旧实现仅在 create 成功后保存id，create失败及异步断线时可能漏清理原生连接句柄；并且共享重连计时器取消后未置空。新版为每次attempt清理原生句柄，停止扫描后等待，133/10003仅有一次有限重试；服务发现、通知订阅、MTU及首条命令逐步校验会话版本；正在恢复时不再嵌套安排重连。没有变更固件或OTA协议。

验证：49项小程序测试通过，包括133失败句柄清理、有限重试、迟到回包不复活连接、隐私原生按钮确认、隐私错误不误报取消、相册保存成功/拒绝。语法检查及微信工具预览编译通过。模拟器 getPrivacySetting 返回正式隐私指引名及 needAuthorization:false；不能以模拟器替代用户手机的授权状态。无可读取的手机蓝牙日志，因此截图133的实际硬件诱因和实体相册写入仍待真机验收，不能承诺133已在实体设备消失。
