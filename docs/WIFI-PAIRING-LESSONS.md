# Wi-Fi 在线后被身份核验重连：2026-11-04

实机日志在北京时间 15:45:17 回报 wifi:online，随后身份核验发送 0x3E、0x38，15:45:19 回报 wifi:offline；15:46:26 恢复 online 后再次重复。

核对已发布 ritual.6 源码归档：0x38 调用 service_wifi_connect，最终 hal_wifi_connect 先 esp_wifi_disconnect，再设置配置并连接。它不是单纯的“检查同步”命令。不能用它在每次已联网的身份核验或同步检查中唤醒心跳。

网页核验期间曾暂停外层状态轮询，只保留瞬间的 offline 显示；该日志不能证明之后整分钟一直断网。失败后在线回报又会触发新的自动核验，形成反复重连。

修正规则：

- 在线身份核验保留 Wi-Fi，等待认证心跳；仅当 0x3A 明确离线时发起一次连接。
- 核验轮询同时读取 0x3A，持续展示实际联网状态。
- 同一账号、同一次蓝牙连接只自动核验一次；失败保留错误，允许手动重试。
- 发布后检查同步也先查询状态，不在已在线时发送 0x38。
- 不通过蓝牙读取 Wi-Fi 密码，不更改固件或放宽云端设备认证。
