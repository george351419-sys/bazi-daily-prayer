## 六、相关按钮与步骤文字

- 生成按钮：生成今日造像；忙碌时“正在为你准备…”。
- 生图重试：重新尝试生图。
- 网页内容准备失败：重试同步；小程序：重试准备画屏内容。
- 网页连接入口：去链接神物并同步；小程序：去链接神物 / 检查连接。
- 设备检查：立即检查同步（需蓝牙）。
- 造像进度：核对生辰 → 读懂心愿 → 绘成造像。
- 准备进度：两日画作 → 转换画屏格式 → 保存内容包 → 准备完成。
- 网页同步步骤：内容就绪 → 设备下载 → 传输完成 → 画屏刷新。
- 小程序同步步骤：① 内容就绪 → ② 下载中 → ③ 已保存 → ④ 已刷新。

连接页布局补充：已删除单独的“画屏下载状态”条（原 B13/B14），下载百分比仅由当前内容的主进度卡显示；删除“填写 Wi-Fi 名称和密码”快捷按钮，保留上方表单；“画屏固件更新”折叠入口移至连接页最底部。固件协议及升级路径未改。
